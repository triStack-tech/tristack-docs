Tristack CPaaS is how a Tristack project reaches a person. Every channel takes the same API key,
settles against the same wallet, and is switched on per project, but each one has its own
endpoint, its own request shape and its own price.

<Note>
  The API still says `relay` in its paths (`/v1/relay/...`), request fields, scopes, usage
  product ids and error codes, from the product's earlier name, Tristack Relay. Those are
  unchanged and stay that way, so nothing you have already written needs to move.
</Note>

## What they share

**One key.** A project API key works across every CPaaS channel it has switched on, and across
Manifold AI too. There is no per-channel credential.

**One wallet.** A call, an email and a Manifold request all draw on the same balance. There is
no per-channel or per-project balance to top up separately.

**One switch each.** Every channel is enabled per project, independently. Turning Email on does
nothing to Voice, and a key on a project with the channel off is refused with that channel's
own `..._disabled` code.

## What they do not share

**Nothing passes between them automatically.** Voice will not read an email out loud, and
Email will not send a transcript of a call. Text produced by one channel is just text to
another, and passing it across is something your code does deliberately.

**Prices are per channel and not comparable.** A voice call is priced by the characters it speaks, an
email per recipient, a WhatsApp or SMS code per code sent. There is no shared unit, and a rupee
buys a different amount of each.

**WhatsApp has a second bill that the others do not.** You hold the Meta relationship, so
Meta bills you separately for WhatsApp messages, on top of what Tristack charges. Voice, Email
and SMS have one bill: ours.

**Request shapes differ.** They all use `camelCase` on the wire, unlike Manifold's
`snake_case`, but the fields themselves have nothing in common: Voice takes phone numbers and a
voice alias, Email takes addresses and a verified sending domain, and WhatsApp and SMS take one
number and return an id to verify against.

## Tristack CPaaS and Manifold AI

Manifold AI is the other platform, and it is not part of Tristack CPaaS. Manifold generates
text; Tristack CPaaS delivers messages to people. They share an account, a wallet and a key
scheme and nothing else. [The platforms page](/platform/products) draws that line in detail.
