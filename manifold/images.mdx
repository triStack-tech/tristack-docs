`POST /v1/manifold/images` turns a text prompt into one image, billed per image from the same
prepaid wallet as everything else in Manifold. The image comes back inside the response, as
base64.

```json A request
{
  "model": "stable-image-core",
  "prompt": "A steel water bottle on a wooden table, morning light",
  "aspect_ratio": "1:1"
}
```

```json The reply
{
  "id": "img_5c1e...",
  "model": "stable-image-core",
  "images": [
    { "index": 0, "b64": "iVBORw0KGgoAAAANSUhEUgAA...", "media_type": "image/png", "seed": 2481937705 }
  ],
  "usage": { "images": 1 },
  "cost": { "paise": 420 }
}
```

## Read this before you build on it

Five things about images work differently from the rest of Manifold, and each one changes the
code you write around the call.

<Warning>
  **Each model makes one image per minute, for the whole platform.** Not per key and not per
  account: one image a minute per model, shared by every Tristack customer, and the limit
  cannot be raised. When the model's slot is taken, the request is refused at once with
  `429 model_busy` and a `Retry-After` header, and nothing is charged. Your code has to wait
  and retry. See [One image a minute per model](#one-image-a-minute-per-model).
</Warning>

- **Images are processed outside India.** Every image model is served from outside the
  country, so the prompt you send, and the image made from it, leave India. See
  [Where your prompt is processed](#where-your-prompt-is-processed).
- **Words inside images are not reliable.** Signs, banners, labels and logos that carry text
  usually come out misspelt. See [Words inside images](#words-inside-images).
- **You pay only for an image you receive.** A blocked prompt is not charged, and neither is a
  busy model or a failed call. Each request makes exactly one image.
- **The image is in the response and nowhere else.** It comes back as base64 only. There are no
  image URLs, and Tristack does not store the images, so save it when it arrives.

## Make an image

```bash Generate one, and keep the reply
curl -s https://api.tristack.tech/v1/manifold/images \
  -H "Authorization: Bearer $TRISTACK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "stable-image-core",
    "prompt": "A steel water bottle on a wooden table, morning light",
    "aspect_ratio": "3:2",
    "output_format": "jpeg"
  }' \
  -o reply.json
```

An image usually takes 5 to 15 seconds. Give whatever client you use a timeout of two minutes,
so a slow image is not cut off before it arrives.

### Turn the base64 into a file

`images[0].b64` is the whole image file, base64 encoded, and `images[0].media_type` says
whether it is a PNG or a JPEG.

<CodeGroup>

```bash curl and jq
if jq -e '.images' reply.json > /dev/null; then
  jq -r '.images[0].b64' reply.json | base64 --decode > bottle.jpg
  jq -r '"seed \(.images[0].seed), cost \(.cost.paise) paise"' reply.json
else
  jq -r '"\(.code): \(.error)"' reply.json   # refused: why
fi
```

```python Python
import base64
import json

with open("reply.json") as source:
    reply = json.load(source)

image = reply["images"][0]
suffix = ".jpg" if image["media_type"] == "image/jpeg" else ".png"
with open("bottle" + suffix, "wb") as out:
    out.write(base64.b64decode(image["b64"]))

print(f"seed {image['seed']}, cost {reply['cost']['paise']} paise")
```

</CodeGroup>

## Choosing a model

| Alias | Model | Image at `1:1` | Price per image |
|---|---|---|---|
| `stable-image-core` | Stable Image Core | 1536 × 1536 px | The lowest of the three |
| `sd-3-5-large` | Stable Diffusion 3.5 Large | 1024 × 1024 px | Between the other two |
| `stable-image-ultra` | Stable Image Ultra | 1024 × 1024 px | The highest of the three |

**Start with `stable-image-core`.** It is the best value of the three and it gives the largest
image. All three produce good photographs. Compare the other two on your own prompts before
paying more for every image.

Each model is billed **per generated image** from the wallet. The current price is
`paisePerImage` on [`GET /v1/manifold/models`](/api-reference/manifold/models), and one image
costs that figure rounded up to a whole paise. Prices are set in rupees from the exchange rate,
so they move: read them from the endpoint rather than copying them into your code. How the
charge works is on [Pricing](/manifold/pricing#images).

Each model also has a one-a-minute slot of its own, so a second model is your fallback when the
first is busy.

## Aspect ratios

`aspect_ratio` sets the shape of the image. It defaults to `1:1`.

| `aspect_ratio` | Shape | Good for |
|---|---|---|
| `1:1` | Square | Product tiles, social posts, avatars |
| `16:9` | Landscape | Banners, slides, video thumbnails |
| `21:9` | Wide landscape | Website header strips |
| `3:2` | Landscape | Photographs |
| `5:4` | Nearly square, landscape | Prints and frames |
| `4:5` | Nearly square, portrait | Portrait posts in social feeds |
| `2:3` | Portrait | Posters and covers |
| `9:16` | Tall | Stories, reels and phone screens |
| `9:21` | Very tall | Tall mobile banners |

Any other value is refused with `400 invalid_request`, before anything is charged.

The sizes in the model table are for `1:1`. Another ratio changes the shape of the image and
so its width and height: read them from the file you receive rather than assuming them.

### PNG or JPEG

`output_format` is `png` (the default) or `jpeg`. A square image from `stable-image-core` is
about 3 MB as PNG and about 0.7 MB as JPEG, and base64 makes the reply about a third larger
again. For photographs you will put on a web page, ask for `jpeg`.

## The same image again: seeds

Every image comes back with the `seed` it was made from. Send that seed again with the same
model, prompt, negative prompt and aspect ratio, and you get the same picture again.

```json
{
  "model": "stable-image-core",
  "prompt": "A steel water bottle on a wooden table, morning light",
  "seed": 2481937705
}
```

`seed` is a whole number from 0 to 4294967294. Leave it out, or send `0`, and the model picks
one at random; the reply tells you which it picked.

- **Keep the seed with the prompt.** A result someone approved can then be made again, exactly,
  instead of hoping a new roll comes out as well.
- **Change one thing at a time.** Hold the seed fixed while you adjust the wording, so the
  difference between two images comes from the prompt rather than from chance.

Every image is a billed request, and each model makes one a minute, so explore with a handful of
seeds, not hundreds.

## Negative prompts

`negative_prompt` lists what you do not want in the image, up to 10,000 characters:

```json
{
  "model": "sd-3-5-large",
  "prompt": "A busy vegetable market in Pune at dusk, photograph",
  "negative_prompt": "blurry, cartoon, watermark"
}
```

Put exclusions here rather than in the prompt. A model reads the words of a prompt as things to
draw, so "a beach with no people" can bring people in. Ask for "a beach" and put `people` in
`negative_prompt` instead.

## Words inside images

Ask for a shop sign that reads "Diwali Sale" and you will usually get a sign covered in
near-letters that spell nothing, something like "DAWAL SAALE DWALL". **Text inside an image is
not reliable on any of the three models**, and Stable Image Ultra tends to leave it out
altogether.

Generate the picture without the words, and put the text on afterwards in your own design tool
or code, where the spelling and the font are yours to control. Adding `text, letters, words` to
`negative_prompt` can help keep stray lettering out of the background.

## One image a minute per model

Each image model makes **one image per minute for the whole Tristack platform**. The slot is
shared by every customer: it is not per key and not per account, and it cannot be raised. The
three models have a slot each.

When the slot is taken, by you or by anyone else, the request is refused at once, before your
wallet is touched:

```http 429 model_busy
HTTP/1.1 429 Too Many Requests
Retry-After: 37
Content-Type: application/json

{ "error": "This model is busy. Try again in 37 seconds.", "code": "model_busy", "retry_after_seconds": 37 }
```

`Retry-After` and `retry_after_seconds` say the same thing: how many seconds until the model's
next slot. Wait that long, then send the request again. Someone else may take that slot first,
so retry in a loop with a limit rather than once:

```python Wait for the slot, then retry
# pip install requests
import base64
import os
import time

import requests

URL = "https://api.tristack.tech/v1/manifold/images"
HEADERS = {"Authorization": f"Bearer {os.environ['TRISTACK_API_KEY']}"}


def generate(body: dict, attempts: int = 5) -> dict:
    for attempt in range(attempts):
        reply = requests.post(URL, headers=HEADERS, json=body, timeout=120)
        busy = reply.status_code == 429 and reply.json().get("code") == "model_busy"
        if not busy or attempt == attempts - 1:
            break
        time.sleep(int(reply.headers.get("Retry-After", "60")) + 1)

    if not reply.ok:
        failure = reply.json()
        raise RuntimeError(f"{reply.status_code} {failure.get('code')}: {failure['error']}")
    return reply.json()


result = generate(
    {"model": "stable-image-core", "prompt": "A steel water bottle on a wooden table"}
)
with open("bottle.png", "wb") as out:
    out.write(base64.b64decode(result["images"][0]["b64"]))
```

Three habits make the limit easy to live with:

- **Make images in the background.** A person will wait 5 to 15 seconds for an image; they
  cannot be asked to wait for a slot another customer holds. Generate from a job queue and show
  the result when it arrives.
- **Fall back to another model.** If any of the three will do, try the next alias when one
  answers `model_busy`. Each has its own slot, its own price and its own image size.
- **Respect `Retry-After`.** A busy answer costs nothing, but sending again before the time is
  up only earns another `model_busy`.

## What an image costs

Images are billed **per generated image**, never per token, from the same wallet as the rest of
Manifold. The price of one image is held before the model runs, charged when an image comes
back, and released in full when none does.

| Outcome | Charge |
|---|---|
| An image came back | The price of one image. `cost.paise` on the reply says what it was |
| `content_filtered`: the safety filter blocked the prompt or the image | Nothing. The hold is released |
| `model_busy`: the model's slot was taken | Nothing. Refused before the wallet is touched |
| `provider_error`: the model failed or timed out | Nothing. The hold is released |
| Refused before the model ran: a bad field, a key without `manifold:image`, a model the project may not use | Nothing |
| `insufficient_balance`: the wallet cannot cover one image | Nothing. The model did not run |

There is no charge for the prompt's length, the aspect ratio or the output format: one image is
one price. See [Pricing](/manifold/pricing#images).

## Blocked prompts

Each model runs a safety filter over the prompt and over the image it makes. When the filter
blocks either, the answer is `400 content_filtered`, and **you are not charged**:

```json 400
{ "error": "The model's safety filter blocked this prompt. You were not charged.", "code": "content_filtered" }
```

The filter belongs to the model, and Tristack cannot switch it off. Rewording the prompt is the
fix. A blocked attempt still used that model's slot for the minute, so the next try may answer
`model_busy` first.

## Where your prompt is processed

Every image model is served from outside India. The prompt you send, and the image made from
it, are processed outside the country, and `GET /v1/manifold/models` reports these models with
`residency` `outside_india`.

If you have a DPDP, BFSI or contractual residency obligation, treat the image models as not
India-resident and keep personal data out of image prompts. The per-alias tables are on
[Where your input is processed](/manifold/models#where-your-input-is-processed).

## OpenAI-compatible alias

If you already have code written against OpenAI's images API, point its base URL at
`https://api.tristack.tech/v1`:

```python
from openai import OpenAI

client = OpenAI(api_key="tsk_...", base_url="https://api.tristack.tech/v1")

result = client.images.generate(
    model="stable-image-core",
    prompt="A steel water bottle on a wooden table, morning light",
    size="1536x1024",
)
```

`size` chooses the aspect ratio, `n` must be 1, and `response_format: "url"` is refused because
no URLs are offered. The alias runs the same code as the native route, so it bills identically
and shares the same one-a-minute limit. [Field by field](/manifold/openai-compatible#images).

## Keys and scopes

A scoped key needs `manifold:image`, for this route and for the OpenAI-compatible alias.
`manifold:invoke` and `manifold:embed` do **not** grant it: a key that may send messages does
not silently gain another way to spend your wallet. A key with no scopes at all can do
everything, as always.

Image models sit in the project's model allowlist like any other model. While the allowlist is
empty, which is how every project starts, the project may call them. Once it has been narrowed,
add the image aliases to it before calling them.

## Errors

| Code | Meaning |
|---|---|
| `model_busy` | `429`. The model's one-a-minute slot is taken. Wait `Retry-After` seconds and retry. Not charged |
| `content_filtered` | `400`. The safety filter blocked the prompt or the image. Not charged |
| `invalid_request` | `400`. A field is missing or out of range: an empty or over-long `prompt`, an unknown `aspect_ratio`, or `n` other than 1 |
| `model_kind_mismatch` | `400`. A text or embedding model sent here, or an image model sent to messages, chat completions or embeddings |

Every code, including the key, scope and wallet ones, is in
[the reference](/api-reference/manifold/images#errors). Codes shared across the API are on
[platform errors](/platform/errors).
