Tristack Relay Email sends transactional email from a domain you own. You prove the domain by
publishing three DNS records, and after that any API key on that project can send from any
address at it.

```bash One request, one email
curl https://api.tristack.tech/v1/relay/email \
  -H "Authorization: Bearer $TRISTACK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "no-reply@yourdomain.com",
    "fromName": "Acme",
    "to": ["customer@example.com"],
    "subject": "Your receipt",
    "text": "Thanks for your order. Your receipt is attached to your account."
  }'
```

```json 202 Accepted
{
  "id": "rle_9f2c1a7b4e6d08a35c1b90fe",
  "messageId": "010901a03e85875a-98c66005-e0a6-4276-af3e-51fb65d8cfc3-000000",
  "costPaise": 2,
  "recipients": 1
}
```

## What it is for

Receipts, password resets, verification links, alerts. One message to one person, or to a
handful. It is not a marketing tool: there is no campaign builder, no list management and no
unsubscribe handling, and sending bulk marketing through it will damage the sending reputation
of every domain on the platform.

## Attaching a file

A message can carry up to ten files, base64 encoded, and your own `X-` headers and tags
alongside them. Give an attachment a `contentId` and it goes inline, so `<img src="cid:logo">`
in your HTML resolves to it.

<Warning>
  The 10 MB ceiling applies to the message **once encoded**, and base64 adds about a third, so
  a 9 MB file does not fit. Keep the files on one message under about 7 MB. Attachments are not
  billed: the charge is per recipient whatever the message weighs.
</Warning>

Executable types (`.exe`, `.scr`, `.bat`, `.cmd`, `.com`, `.pif`, `.js`, `.vbs`, `.jar`) are
refused, by extension and by declared content type. Most mail providers reject these anyway,
so host the file and send a link instead. Full detail in the
[API reference](/api-reference/relay-email/send).

## The two things to know before you start

**You must own the domain.** There is no shared sending domain and no `@tristack.tech` address
you can borrow. That is deliberate: mail sent from a domain the recipient recognises is mail
that arrives, and a shared domain means your deliverability depends on strangers.

**You are billed per recipient, not per message.** An email addressed to fifty people costs
fifty times one addressed to a single person, because that is fifty deliveries. `To`, `Cc` and
`Bcc` all count. See [Pricing](/relay-email/pricing).
